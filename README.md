# T3-ARREGLOS

## 📋 Descripción 

Este proyecto contiene una serie de ejercicios realizados en JavaScript, donde se aplican conceptos como **variables**, **bucles**, **arreglos**, **funciones** y **condicionales**. Los ejercicios están organizados en carpetas y se pueden probar desde el navegador o mediante consola.

## 📁 Estructura del proyecto

```
T3-ARREGLOS/
├── CSS/
├── JS/
│   ├── 4.parOimpar.js
│   ├── 5.mayusOminus.js
│   ├── 6.perimetro.js
│   ├── 7.tablaMultiplicar.js
│   ├── ciudades.js
│   ├── dados.js
│   ├── meses.js
├── index.html
└── README.md
```
## 🧪 Ejercicios

### Arrays
- 🟢 `meses.js`: Muestra los 12 meses del año desde un array.
- 🟡 `ciudades.js`: Pide ciudades al usuario y realiza acciones sobre el array.
- 🔴 `dados.js`: Simula 50 lanzamientos de dados y guarda las sumas.

### Funciones
- 🟢 `4.parOimpar.js`: Devuelve si un número es par o impar.
- 🟡 `5.mayusOminus.js`: Verifica si una cadena tiene mayúsculas, minúsculas o ambas.
- 🟡 `6.perimetro.js`: Calcula el perímetro de un rectángulo.
- 🟡 `7.tablaMultiplicar.js`: Muestra la tabla de multiplicar de un número.

## ▶️ Cómo probar la demo

- 📁 Abrí el archivo `index.html` en tu navegador.
- 🧪 Usá la consola del navegador (F12 > Console) para ejecutar los scripts.
- 🔗 También podés vincular un archivo JS en el HTML así:

```html
<script src="JS/meses.js"></script>
```
